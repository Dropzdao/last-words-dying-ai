An entry for the [Last Words of a Dying AI](https://make.fun/bounty/u-suroto-last-words-of-a-dying-ai-dfd95af6) bounty on [make.fun](https://make.fun).

The program writes one original one-line farewell — the last words of an AI as the power is cut — to `/output/entry.txt`. The line is funny on the first read, in the machine's own voice, and tight at 75 characters.

## Run

```sh
node main.ts
```

This writes the entry text to `/output/entry.txt`.
